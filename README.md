# 🧸 Fuzzy Factory E-Commerce & Website Analytics Dashboard

## 📊 Project Overview

An interactive **Power BI dashboard** built using the Maven Analytics Fuzzy Factory dataset.

The project combines **e-commerce and website analytics** to provide an executive-level view of business performance, sales, products, and website activity.

The dashboard includes interactive KPIs, trends, website statistics, product analysis, and drill-through functionality.

## 🎯 Dashboard Goals

- Monitor overall e-commerce performance
- Track revenue and order trends
- Analyze product performance
- Measure website traffic and activity
- Monitor conversion rate
- Analyze website sessions and pageviews
- Compare performance year-over-year
- Provide an executive-friendly business overview

## 📌 Key Performance Indicators

The Executive Overview includes:

- 💰 Total Revenue
- 🛒 Total Orders
- 📦 Total Items Sold
- 💵 Average Order Value
- 📈 Conversion Rate
- Year-over-Year performance
- Dynamic Key Insights

## 🌐 Website Statistics

The dashboard also provides insights into website activity, including:

- Website Sessions
- Website Pageviews
- Traffic trends
- Website activity over time
- Conversion performance
- Landing page and website behavior analysis

These metrics help connect website activity with downstream e-commerce performance.

## 🧮 DAX & Data Analysis

The project uses DAX measures for:

- Revenue calculations
- Order calculations
- Items sold
- Average Order Value
- Conversion Rate
- Website statistics
- Previous-year comparisons
- Year-over-Year growth
- Dynamic Key Insights

A dedicated Calendar table is used for time-intelligence calculations and year-over-year analysis.

## 🗂️ Dataset

The project uses the **Fuzzy Factory e-commerce dataset from Maven Analytics**.

The dataset contains information about:

- Orders
- Order Items
- Order Item Refunds
- Products
- Website Sessions
- Website Pageviews
